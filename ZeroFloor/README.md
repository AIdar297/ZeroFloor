# «Нулевой этаж» — визуальная новелла

C# · WPF · .NET 10 · Visual Studio 2026.

## Текущее состояние

- **UI полностью реализован**: главное меню (6 пунктов), игровой экран (фон/силуэт-заглушка/
  диалог/выбор/журнал/пауза/скрытие интерфейса), подтверждение выхода, экран загрузки,
  уведомления о сохранении — на собственном тёмном стиле, масштабируется под 1920×1080.
- **Движок визуальной новеллы реализован и протестирован** (`Engine/`, `Services/`):
  сцены, диалоговые узлы, выборы с условиями/эффектами, переходы, скрытые проверки,
  4 канонические концовки (Gate10), JSON-формат сценария, защита от некорректных данных
  и повторного применения эффектов. 101 тест в `ZeroFloor.Tests` — все проходят.
- **Экран новеллы и движок пока не соединены**: `NovelViewModel` показывает свою
  встроенную демонстрационную последовательность реплик (честно помечена как временная),
  а не читает `Data/Scenario/*.json` через `GameSessionController` — это следующий шаг.
- **Реальный сюжет (12 глав) ещё не перенесён в данные** — `Data/Scenario/` пока пуста;
  реальные изображения/звук тоже не добавлены — `Assets/` ждёт файлов от автора.

## Требования

- **Visual Studio 2026** с установленной нагрузкой **.NET desktop development** (WPF).
- **.NET 10 SDK** (устанавливается вместе с нагрузкой выше; для сборки из командной строки
  можно проверить версию командой `dotnet --version`).
- Windows 10/11 x64.

## Как открыть проект в Visual Studio 2026

1. Запустить Visual Studio 2026.
2. «Открыть» → «Открыть проект или решение…».
3. Выбрать файл **`ZeroFloor.slnx`** в корне репозитория (`C:\Users\kanal\source\repos\FirstProject\ZeroFloor\ZeroFloor.slnx`).
   `.slnx` — современный XML-формат решения Visual Studio (замена `.sln`), открывается точно так же.
4. Дождаться восстановления NuGet-зависимостей (проект их не использует, поэтому это займёт секунды).
5. Нажать **F5** (или «Запустить» ▶) — откроется главное меню игры.

## Сборка и запуск из командной строки

```bash
dotnet build ZeroFloor.slnx
```

```bash
dotnet run --project ZeroFloor/ZeroFloor.csproj
```

## Тесты движка

```bash
dotnet test ZeroFloor.slnx
```

Запускает `ZeroFloor.Tests` (xUnit) — 101 тест на `ConditionEvaluator`, `EffectApplier`,
`ChoiceProcessor`, `SceneManager`/`DialogueManager`, `ScenarioValidator`, `ScenarioRepository`,
`EndingManager` (повторяет тест-план T07–T11 из `PROJECT_ANALYSIS.md`) и сквозной прогон
`GameSessionController` на тестовом сценарии (`ZeroFloor.Tests/Fixtures/`, не реальный сюжет).

## Структура проекта

Подробный путеводитель — [PROJECT_STRUCTURE.md](PROJECT_STRUCTURE.md). Коротко:

| Папка | Содержит |
|---|---|
| `Views/`, `ViewModels/` | Экраны игры (MVVM), реализовано |
| `Models/` | Данные: состояние игры, сцены, диалоги, выборы, условия, сохранения |
| `Engine/` | Движок визуальной новеллы — реализовано и протестировано |
| `Services/` | Навигация, логирование, загрузка/валидация сценария (`ScenarioRepository`, `Services/Json/`); сохранения/ассеты/аудио/настройки — пока только in-memory заглушки для UI |
| `Styles/` | Темы/стили WPF |
| `Common/` | Базовая MVVM-инфраструктура |
| `Data/` | JSON-сценарии и данные персонажей (пока пусто — реальный сюжет ещё не перенесён) |
| `Assets/` | Изображения и звук (пока пусто — ждут реальных файлов) |
| `docs/` | Исходные документы сценария |
| `ZeroFloor.Tests/` *(отдельный проект)* | Тесты движка (xUnit) + тестовые JSON-фикстуры |

## Обработка ошибок

Необработанные исключения UI-потока перехватываются (`DispatcherUnhandledException`),
логируются в файл и показываются пользователю как понятное сообщение — приложение не
закрывается аварийно без объяснения. Лог пишется в
`%LOCALAPPDATA%\ZeroFloor\logs\log-<дата>.txt`.
